# Syncfusion&reg; JavaScript (ES5) DOCX Editor (Document Editor) - WebMCP Getting Started

This sample demonstrates how to enable and configure the WebMCP (Model Context Protocol) support in the Syncfusion<sup style="font-size:70%">&reg;</sup> JavaScript (ES5) DOCX Editor (Document Editor) using the `DocumentEditorContainer` component with the Ribbon toolbar.

# Key Features

* [Enables WebMCP support](https://help.syncfusion.com/document-processing/word/word-processor/javascript-es5/overview?utm_source=github&utm_medium=listing&utm_campaign=github-javascript-es5-docx-editor-examples) in the Document Editor Container using the `enableWebMcp` property, allowing AI agents to interact with the editor through the Model Context Protocol.
* Registers the editor as a WebMCP tool provider using the `webMcpSettings` property, so AI assistants (like Chrome's built-in AI agent) can discover and invoke document editing tools.
* Retrieves the list of registered WebMCP tools using the `getWebMcpTools` method, which exposes editing, formatting, and document management operations to connected AI clients.
* Supports intercepting WebMCP tool executions with the `beforeWebMcpToolExecute` event, allowing you to validate or restrict tool usage before it runs.
* Shows a [confirmation dialog](https://help.syncfusion.com/document-processing/word/word-processor/javascript-es5/dialog?utm_source=github&utm_medium=listing&utm_campaign=github-javascript-es5-docx-editor-examples) for write operations such as `replaceAll`, `insertText`, `paste`, `insertBookmark`, `enforceProtection`, `stopProtection`, `insertField`, `insertEditingRegion`, `formatCharacter`, `formatParagraph`, `insertImage`, and `insertHyperlink`, preventing unintended modifications by AI agents.
* Supports the [ribbon interface](https://help.syncfusion.com/document-processing/word/word-processor/javascript-es5/ribbon?utm_source=github&utm_medium=listing&utm_campaign=github-javascript-es5-docx-editor-examples) using the `toolbarMode` property set to `Ribbon`, providing tab-based commands similar to Microsoft Word.
* Supports document elements like text, [image](https://help.syncfusion.com/document-processing/word/word-processor/javascript-es5/image?utm_source=github&utm_medium=listing&utm_campaign=github-javascript-es5-docx-editor-examples), [table](https://help.syncfusion.com/document-processing/word/word-processor/javascript-es5/table?utm_source=github&utm_medium=listing&utm_campaign=github-javascript-es5-docx-editor-examples), fields, [bookmark](https://help.syncfusion.com/document-processing/word/word-processor/javascript-es5/bookmark?utm_source=github&utm_medium=listing&utm_campaign=github-javascript-es5-docx-editor-examples), [shapes](https://help.syncfusion.com/document-processing/word/word-processor/javascript-es5/shapes?utm_source=github&utm_medium=listing&utm_campaign=github-javascript-es5-docx-editor-examples), [section](https://help.syncfusion.com/document-processing/word/word-processor/javascript-es5/section-format?utm_source=github&utm_medium=listing&utm_campaign=github-javascript-es5-docx-editor-examples), [header and footer](https://help.syncfusion.com/document-processing/word/word-processor/javascript-es5/header-footer?utm_source=github&utm_medium=listing&utm_campaign=github-javascript-es5-docx-editor-examples).
* Provides support to [find and replace](https://help.syncfusion.com/document-processing/word/word-processor/javascript-es5/find-and-replace?utm_source=github&utm_medium=listing&utm_campaign=github-javascript-es5-docx-editor-examples) text within the document.
* Supports all the common editing and formatting operations along with [undo and redo](https://help.syncfusion.com/document-processing/word/word-processor/javascript-es5/history?utm_source=github&utm_medium=listing&utm_campaign=github-javascript-es5-docx-editor-examples).
* Provides a [server-side helper library](https://help.syncfusion.com/document-processing/word/word-processor/javascript-es5/web-services-overview?utm_source=github&utm_medium=listing&utm_campaign=github-javascript-es5-docx-editor-examples) to open the Word documents like DOCX, DOC, WordML, RTF, and Text, by converting it to SFDT file format.
